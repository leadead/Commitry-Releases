# Commitry

macOS 原生 Git 客户端：提交、分支、合并 / 变基 / cherry-pick、交互式变基、冲突解决、Git-Flow，以及 GitHub / GitLab / Backlog 的 PR / MR 只读审查。仓库、托管账号、令牌、SSH 密钥和设置保存在 iCloud，换机后自动恢复，并能一键把仓库克隆回原位置。

界面支持简体中文、English、日本語、Tiếng Việt。

## 下载与安装

系统要求：macOS 27 及以上，Apple Silicon；需要 Xcode 命令行工具（git 2.34+，未安装时 App 会引导安装）。

1. 下载 [Commitry.zip](https://github.com/leadead/Commitry-Releases/releases/latest/download/Commitry.zip)（[所有版本](https://github.com/leadead/Commitry-Releases/releases)）
2. 解压后把 Commitry 拖入「应用程序」

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在 Commitry 菜单中点「检查更新…」。

## 隐私

Commitry 不采集、不上传任何数据，只访问你配置的 Git 服务器、托管平台 API 和更新地址。
